# TCS-Equity-Valuation-DCF-P/E-Model

## Overview
Built a comprehensive financial model to estimate the intrinsic value of Tata Consultancy Services (TCS) using DCF and P/E valuation techniques.

## Key Analysis Performed
- Calculated weekly returns and Beta using the covariance & variance approach.
- Estimated Cost of Equity using the CAPM model.
- Derived Cost of Debt and calculated WACC.
- Projected future cash flows based on financial trends.
- Performed Discounted Cash Flow (DCF) valuation.
- Estimated Terminal Value and calculated intrinsic valuation of TCS  using DCF and P/E model.

## Key Concepts Applied
- CAPM
- WACC
- Beta
- DCF Valuation
- Terminal Value

- Hands-on experience in financial modeling
